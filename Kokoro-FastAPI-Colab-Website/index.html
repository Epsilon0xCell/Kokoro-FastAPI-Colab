Kokoro-FastAPI-Colab

One Colab notebook starts the Kokoro speech service on a T4 graphics card and opens it to the internet. That is the whole offer: a voice with no face, sent out wearing this one.

OPEN INColab THERepo

BENCH ONE, PAPER AND GLUEThe notebook itself

One notebook, launch_kokoro.ipynb, opened in Colab, its cells run from the top. Nothing is installed on your own machine. The notebook has 4 cells: a markdown intro, one code cell, a browser-console keep-alive snippet, and the ngrok guide.

BENCH TWO, THE MOULD TAKES SHAPEThe service starting

The code cell installs requests, loguru, and pyngrok, clones remsky/Kokoro-FastAPI, starts its GPU server on port 8880, waits up to 180 seconds for the API, and tests it there before any stranger can reach it. In Colab, set the runtime first: Runtime, Change runtime type, T4 GPU. Set NGROK_AUTH_TOKEN in the configuration cell to your ngrok auth token; the placeholder value is rejected with a clear error.

BENCH THREE, THE MASK LEAVES THE SHOPThe tunnel

ngrok carries the service out through one public address. Copy that address whole, because a tunnel address pasted wrong is a mask tied to the wrong face. An optional static domain can be set with NGROK_CUSTOM_DOMAIN; the notebook falls back to a standard ngrok URL if the custom domain fails.

https://your-tunnel-address.ngrok-free.app (yours is printed by the notebook)
Bench advice: copy the address whole, every character. Half an address reaches nobody.

BENCH FOUR, CARNIVALThe clients

Point SillyTavern or any other OpenAI compatible client at the public address. Text goes in, speech comes back. The mask is finally talking in someone else's rooms.

The upstream Kokoro-FastAPI project and ngrok, where the free account, auth token, and reserved domain steps live.

CLOSING BENCH, REPAIRSTwo ordinary sorrows

The tunnel address dies when the notebook session dies. A restarted session mints a new one, and the new address must be pasted into the client again. That is the whole repair: run, copy, paste.

Bench advice: tunnel addresses change at every restart. When the voice stops answering, check the address first.
